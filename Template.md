# 10. Fact Check

Pisahkan informasi berdasarkan tingkat kepastian.

| Statement | Classification | Source | Notes |
|-----------|----------------|--------|-------|
| | Documented | | |
| | Supported | | |
| | Alleged | | |
| | Speculation | | |
| | Debunked | | |

### Classification

**Documented**  
Didukung dokumentasi atau sumber primer yang kuat.

**Supported**  
Memiliki bukti yang cukup, tetapi belum konklusif.

**Alleged**  
Merupakan klaim dari seseorang atau sumber tertentu.

**Speculation**  
Interpretasi, dugaan, atau kesimpulan yang belum memiliki bukti cukup.

**Debunked**  
Memiliki bukti kuat yang menunjukkan bahwa klaim tersebut keliru.
